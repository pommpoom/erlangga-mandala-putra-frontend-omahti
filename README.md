# OmahFE — Frontend Recruitment Assignment

A responsive landing page built for the **OmahTI UGM Frontend Developer Open Recruitment 2026/2027** assignment. The website is implemented from the provided Figma design using vanilla HTML, CSS, and JavaScript.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frontend frameworks or UI libraries are used.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Sticky navbar with in-page navigation
- Portfolio cards with animated Show More / Show Less
- Testimonial carousel with sliding transitions
- FAQ accordion with smooth expand / collapse
- Contact form with client-side validation (demo only)
- Subtle hover effects and smooth scrolling
- FE logo favicon and external social media links
- Reduced-motion support for animations

## Running Locally

1. Clone or download this repository.
2. Open `index.html` in a browser, or run it using the **Live Server** extension in VS Code.

No installation or build step is required. An internet connection may be needed to load the web fonts.

## Notes

The contact form is a frontend demo and does not send messages to a server. Sign In and Sign Up are display-only buttons. Social media icons currently link to the platforms' homepages as placeholders.
